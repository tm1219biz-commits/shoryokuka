採択率約95%の「穴場」補助金：
省力化投資補助金（カタログ注文型）の全貌

従業員0名（個人事業主）から最大500万円・累計最大3,000万円。なぜ当初目標12万件の6%未満しか採択されていないのか、いくら受給でき、12月3日のルール変更で何に注意すべきかを1ページで整理する。

従来の事業再構築やものづくり補助金とは異なり、中小企業庁等が推進する「省力化投資補助金（カタログ注文型）」は、事務局のカタログに登録された省力化製品を選んで共同申請する簡易な制度です。締め切りに縛られない随時申請・随時発表方式を採用し、上限額に達するまで複数回申請できる一方、制度構造上のボトルネックから利用が伸び悩み、予算が潤沢に残されています。

BOTTLENECK A // 供給・制度側の要因

カタログ掲載製品の不足と登録遅延

工業会などの業界団体による製品カテゴリーの確認・登録フローに時間を要しています。全208件の製品カテゴリーのうち42カテゴリーで登録製品が0件となっており、事業者が導入したくても選択肢が存在しない領域が残っています。

BOTTLENECK B // 需要・申請側の要因

「登録販売事業者」探しと制度の認知不足

本補助金は指定の登録販売事業者との共同申請が必須です。製品を見つけても連携できるパートナー企業を見つけにくい点や、従来型補助金と運用が大きく異なるため情報が届いていない点が申請数の伸び悩みにつながっています。

CRITICAL SCOPE // 他補助金との決定的違い

対象外：新規事業の開発、新規創業、既存事業の新分野展開。
対象：既存事業においてカタログ登録済みの省力化製品を導入し、業務の省力化を達成することのみが対象です。

04 / RULE CHANGE 11月10日発表 // 12月3日からの制度変更点

12月3日ルール変更：大幅賃上げ枠は「交付決定翌月 vs 実績報告直近月」の+3%判定へ

通常枠での申請者は確認不要。補助上限額を引き上げる目的で「大幅な賃上げ」を選択する事業者のみ、新たな判定基準・タイミングおよび未達成時の減額ペナルティに厳重な管理が求められます。

05 / WORKFLOW 準備から受給・効果報告までの4ステップ

交付決定から受給までの4ステップと「事前着手の厳禁」ルール

随時申請・随時発表のため迅速な交付決定が期待できますが、交付決定通知の受領前に発注・契約した案件は一切補助対象外となります。各ステップをクリックして実務手順を確認してください。

STEP 01 // 事前準備 申請前の必須準備
